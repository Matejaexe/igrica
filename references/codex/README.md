# Local Visual Reference Folder

Put user screenshots/videos here when useful.

Recommended structure:

```text
references/codex/current/
references/codex/desired/
references/codex/inspiration/
```

Useful filenames:

```text
current_run_front.png
current_run_side.png
desired_sprint_front.png
desired_sprint_side.png
current_wall_run.mp4
current_swing_release.mp4
current_city.png
menu_mood_reference.png
```

When attaching a reference to Codex, explain WHAT to extract.

Example:

```text
Use this sprinter image only for elbow-to-torso spacing and forward/back arm
plane. Do not copy body proportions/clothing.
```

For copyrighted games, prefer links in `docs/codex/REFERENCES.md` and your own
screenshots/recordings for debugging rather than committing large copied asset
collections into the repository.

# Spider-Man 2 (2004) traversal

GDC Vault — Jamie Fristrom classic postmortem:
https://www.gdcvault.com/play/1025725/Classic-Game-Design-Postmortem-Swinging

Key design themes:

- physics/control/flow trade-offs
- 3D swinging can become too difficult if not assisted carefully
- accessibility should preserve movement depth

A modern retrospective/interview also documents the shift from cosmetic
swinging toward physical attachment/pendulum behavior and momentum-preserving
release.

# Ultimate Spider-Man (2005)

Useful historical controls documented by period guides include:

- Web Swing
- Web Zip
- Wall Run
- swing speed boost
- web climb

Use as traversal-vocabulary reference, not source code/specification.

# Modern Marvel's Spider-Man — secondary polish reference

PlayStation Blog traversal hands-on:
https://blog.playstation.com/2018/06/15/playing-marvels-spider-man-made-me-feel-like-spider-man/

Key theme:

- swing, wall-run and web zip connect fluidly

Insomniac tech interview:
https://blog.playstation.com/2018/09/06/insomniac-interview-the-tech-behind-marvels-spider-man/

Key themes:

- webs attach to actual tagged architecture
- attachment selection helps preserve momentum/direction
- animation/camera/FOV help sell superhero motion beyond literal physics

Insomniac accessibility documentation confirms an explicit Air Trick mode in
modern Spider-Man games. This is useful evidence that air tricks can be a
separate expressive traversal layer.

# Human locomotion research

Pontzer et al. — arm swing in walking/running:
https://pubmed.ncbi.nlm.nih.gov/19181900/

Arellano & Kram — straight-arm walking / bent-arm running:
https://pubmed.ncbi.nlm.nih.gov/31289110/

Active arm swing / rotational stability:
https://pubmed.ncbi.nlm.nih.gov/39900823/

Olympic sprinter arm-swing biomechanics:
https://pmc.ncbi.nlm.nih.gov/articles/PMC13341810/

Use these for broad biomechanics reasoning. Do not convert one study's exact
measured angles into universal animation rules.
